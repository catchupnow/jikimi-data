바로PDF 개인정보처리방침

앱: 바로PDF (Android, 패키지 com.baropdf.app) · 버전 1.0.0 · 시행일 2026년 11월 21일

요약: 바로PDF는 회원가입이 없고, 사용자가 고른 사진·PDF를 기기 안에서만 처리합니다. 파일 내용이나 파일명을 바로PDF 서버로 보내지 않으며, 광고·분석·인앱 결제 SDK를 사용하지 않습니다.

1. 적용 범위

이 방침은 바로PDF Android 앱 1.0.0의 문서 처리 기능에 적용됩니다. 운영자 표시명은 바로PDF이며, 문의 이메일은 liferedesign9@gmail.com입니다.

2. 기기 내 문서 처리

앱은 회원가입이나 로그인을 요구하지 않습니다. 사용자가 선택한 사진과 PDF는 기기에서 처리하며, 파일 내용이나 파일명을 바로PDF 서버로 전송하지 않습니다. 원본 파일은 덮어쓰지 않고 새 결과 파일을 만듭니다. 편집 중 작업 상태는 지속적으로 저장하지 않습니다.

3. 저장·공유용 임시 파일

저장 또는 공유를 누르면 결과 PDF의 임시 사본이 앱 전용 캐시에 생길 수 있습니다. 24시간이 지난 항목은 다음 앱 시작 시 정리됩니다. 앱을 다시 열지 않거나 정리에 오류가 있으면 더 오래 남을 수 있으며, Android의 앱 캐시 삭제 기능으로 지울 수 있습니다. 원본 파일이나 사용자가 별도로 저장한 결과 파일은 이 정리 대상이 아닙니다.

4. 외부 앱으로 공유

사용자가 Android 공유창에서 고른 앱에는 선택한 결과 파일이 전달됩니다. 그 앱이 파일을 저장·전송하는 방식은 해당 서비스의 정책을 따릅니다. 바로PDF는 다른 앱으로 전달되거나 사용자가 별도로 저장한 파일을 삭제할 수 없습니다.

5. 기기에 남는 설정과 사용 횟수

앱의 일부 기능 사용 횟수는 기기의 앱 저장소에 남을 수 있으며 바로PDF 서버로 전송하지 않습니다. Android의 앱 데이터 삭제 또는 앱 제거로 초기화할 수 있습니다. 파일 내용과 파일명은 이 사용 횟수에 기록하지 않습니다.

6. 광고와 결제

이 버전에는 광고·분석·인앱 결제 SDK를 연동하지 않았습니다. 추후 기능이 바뀌면 실제 처리 방식에 맞춰 이 안내와 필요한 동의 절차를 먼저 검토합니다.

7. 수집하는 개인정보

  • 바로PDF는 앱 이용을 위해 이름, 전화번호, 이메일 주소, 위치, 연락처 등 개인정보를 수집하지 않습니다.
  • 앱은 사용자 계정을 만들지 않으며, 앱 안에서 서버로 전송되는 데이터가 없습니다.
  • 앱 스토어(Google Play)를 통한 다운로드·결제·오류 보고 과정에서 Google이 처리하는 정보는 Google의 개인정보처리방침을 따릅니다.

8. 사용자의 선택

파일은 사용자가 직접 선택하며 앱은 원본 파일을 변경하지 않습니다. 공유 대상도 사용자가 정합니다. 앱 외부에 저장한 파일은 해당 위치나 서비스에서 직접 관리해야 합니다. 민감한 문서는 기기와 공유 대상의 보안 상태를 확인한 뒤 사용하시기 바랍니다.
